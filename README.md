# Ntrophy Gateway 프론트 (모의 디자인)

설치 없이 `index.html` 또는 `scenario.html`을 브라우저로 열면 됩니다. (글꼴 CDN만 인터넷 필요, 없으면 시스템 글꼴로 표시)

| 파일 | 역할 |
|---|---|
| `index.html` | 관제 대시보드: 관제 / 인증정보·한도 / 접근 통제 / 사고 기록, 우상단 "데모 제어" |
| `scenario.html` | 탈취 시나리오 3칸 화면(사내 · 게이트웨이 · 외부) + 재생 컨트롤 (스페이스 = 재생/정지, 장면 막대 클릭 = 이동) |
| `css/style.css` | 디자인 토큰과 전체 스타일 |
| `js/sim.js` | 가상 세계: 직원·공격자·Mock 공급자·게이트웨이·탐지 규칙, 시나리오 큐 |
| `js/api.js` | 화면이 데이터를 받는 유일한 창구. `MODE` sim/live |
| `js/ui.js` | 두 화면이 같이 쓰는 차트·게이지·토스트·애니메이션 루프 (계획에 없던 파일, 중복 코드 제거용) |
| `docs/API_CONTRACT.md` | 데모 개발자에게 넘길 데이터 모양 |

백엔드 연결: `index.html?mode=live&api=http://localhost:4000&key=demo-admin-key`

디자인 규칙 요약
- 파랑 = 게이트웨이 기록, 주황 = 공급자 보고. 다른 의미로 쓰지 않습니다.
- 상태 색(녹/황/적)은 상태 띠와 차액 게이지에만 칠합니다.
- 화면에서 가장 큰 것은 "설명되지 않는 사용량" 숫자 하나입니다.
